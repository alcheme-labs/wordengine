# Support

GeNewWord Engine is an alpha research preview with no paid support or response-time guarantee.

- Reproducible bugs and documentation problems: open a GitHub issue after checking existing issues.
- Security or confidential conduct reports: use GitHub private vulnerability reporting; never post exploit details or personal information publicly.
- Research discussion and feature proposals: open a narrowly scoped discussion or issue that identifies the actor, canonical owner, observable effect, and readback.

Public-internet deployment, multi-user operation, authentication, durable hosting, and production incident response are not supported.
