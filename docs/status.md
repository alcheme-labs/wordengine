## Honest maturity

This is a bounded Level-3 causal research preview and engineering cockpit. It is suitable for local experimentation, architecture review, causal validation, and contribution. It is not yet a polished game, public hosted service, large-scale world, scientific proof of a universal physical model, or long-term compatibility commitment.

Before the first public tag, the maintainer must close the rights, public identity, GitHub settings, clean Linux/macOS CI, and release checklist gates. Source preparation is not legal authorization to publish.
