# Governance

GeNewWord Engine currently uses a maintainer-led model appropriate to an alpha research preview.

Maintainers accept changes by evidence, architectural fit, safety, and maintenance cost. No test result, schema, or evidence file alone proves a feature complete: acceptance follows a real producer-to-owner-to-effect-to-readback path. Authority, security, privacy, and data-integrity concerns take precedence over delivery speed.

Substantial changes to Field ownership, snapshot semantics, the causal loop, public interfaces, licensing, or project governance require a public design issue before implementation. Routine fixes, tests, and documentation can use ordinary pull requests.

This model may evolve when multiple sustained maintainers and a real contributor community exist. Changes to governance will be recorded in this file.
