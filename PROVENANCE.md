# Source provenance

This public candidate was created as a fresh, allowlisted source export. It does not inherit the private research repository's Git history.

## Included original material

- `world_engine/`: GeNewWord Engine runtime and readback code;
- `scripts/`: bounded localhost demo and validation entrypoints;
- `tests/`: focused unit, negative, causal, server, release, and browser acceptance tests;
- `docs/` and root Markdown files: original project documentation.

These materials are offered under Apache-2.0. Before the first public release, the repository owner must confirm that they have the right to license every included original file and that no employer, institution, client, or collaborator owns conflicting rights.

## Excluded material

No downloaded papers, extracted article text, article mirrors, video transcripts or metadata, external repositories, fonts, images, model weights, internal experiment archives, or generated validation artifacts are included.

## External development dependency

`package-lock.json` resolves Playwright for browser acceptance. It is downloaded from npm and not vendored. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
